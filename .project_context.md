# YouTube Study Companion - Project Context (v2.5.1)

## 📋 Overview
A professional browser extension designed to transform YouTube into a learning workstation. Key features include precise playback controls, A-B looping, marker-based notetaking, and a dedicated video library.

## 🛠️ Tech Stack
- **Manifest Version**: V3
- **Frontend**: HTML5, Vanilla CSS, Vanilla JavaScript
- **Backend (Service Worker)**: `background.js` (Handles state and tab communication)
- **Content Script**: `content.js` (Injects control logic into YouTube)
- **Permissions**: `sidePanel`, `scripting`, `activeTab`, `tabs`, `storage`

## 🚀 Recent Milestones
- **[2.5.1]**: Added bilingual Known Issues documentation; updated User Manual with manual API Key setup for cross-device sync.
- **[2.5.0]**: Official rebranding to "YouTube Study Companion"; launched landing page; optimized clicking response (bubbling phase).
- **[2.4.0]**: Added marker navigation shortcuts and smoother progress bar updates (150ms).
- **[2.3.0]**: Implemented Global Hotkeys (`Alt+Shift+A`, `Alt+Shift+P`) and a more robust message passing system.

## 💎 Design Philosophy & Decisions
- **Dual-Panel Workspace**: Markers and Controls are separated to maximize vertical UI space.
- **Persistent Memory**: "Marker Follow" (auto-scroll) and specific favorite versions are remembered across sessions.
- **Pop-out Synergy**: The sidebar can detach into a floating window, syncing state in real-time with the main sidebar.
- **CSS Standards**: Adhered to modern CSS standards (fixing `line-clamp` and `background-clip` warnings).

## ⚠️ Known Issues & Current Challenges
- **Play/Pause Lag**: Occasional unresponsiveness for the first 2-3 seconds after video switch (Keyboard shortcuts `Space`/`K` work as fallback).
- **Sync Limitation**: Cross-device sync requires a manual API key in `manifest.json` since it's not yet on the Web Store.
- **Monetization (Upcoming)**: Discussed potential move to paid features using tools like **ExtensionPay** or **Stripe**.

## 🎯 Next Steps
1. Refine the monetization implementation plan (leaning towards ExtensionPay for simplicity).
2. Continue optimizing playback synchronization reliability.
3. Polish the landing page for potential store submission.
