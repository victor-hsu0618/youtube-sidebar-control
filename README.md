# YouTube Study Companion v2.6.5

Professional YouTube playback control and learning tool. Transform your YouTube experience into a powerful learning and notetaking workstation.

📖 **[Read the User Manual](docs/USER_MANUAL.md)** | ⚠️ **[Known Issues](docs/KNOWN_ISSUES.md)** | 📺 **[View Presentation Slides](https://youtube-study-companion-a629h17.gamma.site/)**

## 📥 Installation

This project is a browser extension, currently supporting Chrome and Edge browsers. Please follow these steps to install in Developer Mode:

1. **Get the Code**
   
   Download the ZIP file of this project and extract it, or use Git Clone:
   ```bash
   git clone https://github.com/victor-hsu0618/youtube-sidebar-control.git
   ```

### 📦 Installation Steps (Recommended)
1. **Download Repository**: Click the green "Code" button and select **Download ZIP**.
2. **Download Pre-packaged Extension**: Alternatively, you can download [youtube-study-sidebar-v2.6.5.zip](youtube-study-sidebar-v2.6.5.zip) from the root directory.
3. **Extract ZIP**: Extract the file on your computer.
4. **Load into Chrome**:
   - Open Chrome and go to `chrome://extensions/`
   - Enable **Developer mode** in the top right.
   - Click **Load unpacked** and select the extracted folder.

## 🌟 Main Features

### 1. 🎛️ Advanced Playback Control
- **Dual-Panel Workspace**: Dedicated sub-tabs for **Markers** and **Advanced** to maximize vertical space.
- **Collapsible Controls**: Clean UI with collapsible sections for Speed and Loops within the Advanced panel.
- **Integrated A-B Loop**: Set start (A) and end (B) points precisely with **visual markers** directly on the progress bar.
- **Precise Speed Control**: Accordion-style adjustment from 0.25x to 3.0x.

### 2. 💎 Pro Cloud Verification (New)
- **Account Binding**: Automatically detects your Google Account Email.
- **Cloud Authorization**: Managed via Google Sheets backend; permissions follow your account across devices.
- **Activation Codes**: Unlock premium features instantly with an Activation Code provided by the author.

### 3. 🔖 Smart Markers
- **Timestamp Notes**: Add markers at any moment in the video.
- **Instant Jump**: Click any marker to jump precisely to that timestamp.
- **Marker Follow**: Auto-scroll to keep the current marker in view.

### 4. 💾 Library & Gating
- **Video Sessions**: Save multiple sessions (markers, loop points) for any video.
- **Free Version Limits**: Limited to **10 saved videos** and **10 markers per group** for free users.
- **Visual Gating**: Videos exceeding the limit remain visible but are **visually locked (dimmed)**, encouraging a Pro upgrade.

### 5. 🪟 Pop-out & Diagnostics
- **Multi-Screen Support**: Pop out the sidebar as a floating window.
- **Advanced Tools**: Built-in cloud sync refresh and storage usage monitoring in the Advanced panel.

## 🛠️ Usage

1. **Open**: Click the extension icon on a YouTube page.
2. **Control**: Use the **Advanced** tab to adjust speed and diagnostics.
3. **Save**: Click the heart icon to add current video to your library.
4. **Upgrade**: Click **Activate Pro Features** in the Advanced tab and enter your code.
