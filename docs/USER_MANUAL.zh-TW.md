## 1. 介面總覽 (Interface Overview)

啟動 Extension 後，您會看到主畫面。側邊欄設計簡潔，主要分為三個分頁：

*   **Player (播放器)**：主要的操作區域。現在包含兩個內部子分頁：
    *   **Markers (標記)**：做筆記與瀏覽時間戳記的主要空間。
    *   **Advanced (進階)**：調整播放速度、雲端同步刷新、以及處理 **Pro 帳號啟用** 的地方。
*   **Library (影片庫)**：檢視所有您儲存過收藏的影片歷史紀錄。對於免費版用戶，此處限額儲存 **10 部影片**。
*   **Favorites (我的最愛)**：快速存取您標記為「星號/預設」的常用收藏。

![介面總覽截圖](images/interface_overview.png)
*(建議截圖：開啟 Sidebar 後的完整畫面)*

上方標題列右側有一個 **↗️ 箭頭按鈕**，點擊可將視窗獨立出來（Pop-out）。

### 🟢 狀態指示燈
在 **v3.0.0** 版號旁邊，您會看到狀態標示：
- **綠色**：擴充功能已成功連接至 YouTube 影片。
- **灰色**：擴充功能處於待機模式。
- **[新功能] 群組播放橫幅**：啟動「群組播放」時，頂部會顯示綠色狀態列。
- **[新功能] 模式邊框**：播放清單執行時，整個播放器面板會套用綠色邊框特效。

## 2. Pro 帳號與雲端驗證 (Pro Features)

YouTube Study Companion 現在支援雲端帳號綁定。

1.  **自動識別**：系統會自動抓取您 Chrome 瀏覽器登入的 Google 帳號。
2.  **解鎖方式**：進入 **Player -> Advanced**，點擊 **Activate Pro Features** 並輸入由作者提供的 Code。
3.  **權限同步**：啟用後，Pro 狀態會儲存在雲端。即使您更換電腦，只要登入同一個 Google 帳號，權限就會自動恢復。
4.  **免費版限制**：
    *   影片庫 (Library) 最多存儲 10 部影片。
    *   單個影片內部的標記 (Markers) 每組最多 10 個。
    *   超過限制的影片會在 Library 中以「灰色半透明」顯示且無法點擊。

## 3. 播放控制 (Player Controls)

在 Player 分頁的最上方，您可以完全掌控影片播放。

![播放控制區截圖](images/player_controls.png)
*(建議截圖：Player 分頁上半部，包含進度條與播放按鈕)*

### 功能說明：

*   **Video Status**: 顯示目前偵測到的影片標題。
    *   **Auto Detect (🪄)**: 若未偵測到影片，點擊此按鈕重新偵測。
    *   **Save/Heart (❤️)**: 點擊愛心圖示，將目前影片的設定（標記、循環點）儲存到影片庫。
*   **Transport Controls**:
    *   **Restart**: 回到影片開頭。
    *   **-10s / +10s**: 快速倒退或快進 10 秒。
    *   **Play/Pause**: 中央的大型播放/暫停按鈕。
*   **Playback Speed (速度控制)**:
    *   **摺疊面板**：點擊標題或箭頭可展開/收起速度控制項。
    *   **Slider**: 拖曳滑桿可從 0.25x 到 3.0x 精細調整速度。
    *   **Presets**: 快速按鈕 (0.5x, 1.0x, 1.5x, 2.0x)。

## 3. A-B 循環 (A-B Loop)

專為語言學習或樂器練習設計，讓您重複播放特定片段。

![循環控制截圖](images/loop_controls.png)
*(建議截圖：A-B Loop 區域)*

1.  **展開區塊**：點擊 "A-B Loop" 標題以顯示控制項。
2.  **設定起點 (A)**：播放到想要開始的地方，點擊 `S` 按鈕。
3.  **設定終點 (B)**：播放到想要結束的地方，點擊 `E` 按鈕。
4.  **開啟循環**：打開區塊標題中的開關，影片將在 A 與 B 之間無限重複。
5.  **微調**：您可以直接在輸入框修改時間 (格式 mm:ss)。

## 4. 智慧標記 (Smart Markers)

標記功能讓您在影片的時間軸上做筆記，並隨時跳轉回去。

![標記區域截圖](images/bookmarks.png)
*(建議截圖：Markers 區域，包含幾個已建立的標記)*

*   **新增標記**：點擊 `+ Add Marker (A)` 即可在當前時間建立標記。
*   **標記追隨 (Follow)**：開啟 "Follow" 開關，列表會隨影片播放自動滾動。
*   **群組管理 (Groups)**：
    *   透過下拉選單切換群組（如 `Default`, `Study`）。
*   **[新功能] 快捷鍵 R**：按下 **`R`** 可立即重啟最近一次啟動的標記區間。
*   **匯入/匯出**：使用標題列的圖示備份您的標記資料 (JSON 格式)。

## 5. 群組播放與播放清單 (v3.0 全新功能)

「群組播放」讓您可以將收藏夾中的一個群組當作連續播放清單來使用。

### 使用方式：
1.  **啟動群組播放**：進入 **Favorites** 分頁，選擇一個資料夾後點擊 **▶ Play Group**。
2.  **介面變更**：播放器會進入「播放清單模式」，頂部顯示綠色橫幅。此時會出現 **上一步/下一步** 按鈕（僅在此模式下顯示）供您切換影片。
3.  **自動下一首**：當一部影片結束時，系統會自動加載該群組中的下一部影片。
4.  **整合式清單匯入**：
    *   開啟任一 YouTube 播放清單網頁。
    *   進入 **Favorites -> 管理群組 (齒輪圖示)**。
    *   點擊 **偵測並匯入 YouTube 播放清單**。
    *   系統會自動擷取所有標題與 ID，為您建立一個全新的收藏群組。

## 5. 影片庫與我的最愛 (Library & Favorites)

這是一個強大的功能，允許您為**同一部影片**儲存多個不同的「學習情境」。

![影片庫截圖](images/library.png)
*(建議截圖：Library 分頁)*

### 什麼是「影片收藏 (Favorite)」？
當您點擊標題列的愛心圖示 `❤️` 時，您實際上是儲存了一個「收藏」。您可以為同一部影片儲存多次，例如：
*   第一次儲存：專注於「單字筆記」。
*   第二次儲存：專注於「文法分析」。

### 操作方式：
*   **Library 分頁**：列出所有儲存過的影片。
*   **Favorites 分頁**：只顯示您標記為「星號」的收藏。
*   **Clone Session**: 在 Player 頁面，點擊 `Clone` 按鈕可以複製當前的收藏，建立一個新版本。
*   **Set as Default**: 將某個收藏設為該影片的「預設值」，下次打開該影片時會自動載入此設定。

## 6. 浮動視窗 (Pop-out Window)

如果您使用雙螢幕，或希望控制面板獨立於瀏覽器之外，請使用此功能。

1.  點擊標題列右側的 **Pop-out 圖示 (↗️)**。
2.  側邊欄會轉變為一個獨立的小視窗。
3.  **即時同步**：您在浮動視窗的操作，會與原來的側邊欄完全同步。

### 浮動視窗生命週期 (Pop-out Lifecycle)
當您關閉浮動視窗時，如果原始的 YouTube 分頁不在 YouTube 網站上（例如，您切換到了其他網站），則下次重新打開浮動視窗時，您可能需要手動點擊擴充功能圖示來重新啟動它。

## 7. 鍵盤快捷鍵 (Keyboard Shortcuts)

> [!TIP]
> **專業建議**：為了獲得最流暢的體驗，我們強烈建議您盡量使用 **鍵盤快捷鍵** 代替滑鼠點擊 UI。這不僅能大幅提升您的操作速度，還能減少因 UI 渲染或點擊延遲可能產生的異常情況。

YouTube Study Companion 支援豐富的鍵盤快捷鍵，讓您操作更流暢。點擊標題列的 **鍵盤圖示 (⌨️)** 即可開啟/關閉畫面上的快捷鍵對照表。

### 基礎播放控制
*   **Space / K**: 播放 / 暫停。
*   **J / L**: 倒退 / 快進 (10秒)。
*   **, / .**: 上一幀 / 下一幀 (暫停時)。
*   **0-9**: 依百分比跳轉 (影片 0%–90%)。
*   **M**: 靜音 / 取消靜音。
*   **F**: 全螢幕。

### A-B 循環進階操作
*   **`[`**: 設定 A 點 (起點)。
*   **`]`**: 設定 B 點 (終點)。
*   **`{` (Shift+[)**: 跳轉至 A 點。
*   **`}` (Shift+])**: 切換 A-B 循環開關。

### 標記與列表導覽
*   **A**: 在當前時間新增標記。
*   **S**: 切換「標記追隨 (Follow Playback)」模式。
*   **R**: 重啟當前標記區段。
*   **Alt+[ / Alt+]**: 上一部 / 下一部影片 (僅在群組播放模式下)。
*   **↑ / ↓**: 依序瀏覽標記。切換時會自動關閉「跟隨播放」模式)。

## 8. 跨裝置同步 (Cross-Device Sync)
您的設定、書籤與筆記會自動在所有登入相同 Google 帳號的電腦間同步。

**如何啟用：**
1.  在不同裝置上登入同一個 Google Chrome 帳號。
2.  前往 Chrome 設定 (`chrome://settings/syncSetup`)。
3.  在「管理您同步處理的項目」中，確保已勾選 **擴充功能 (Extensions)**。
4.  本擴充功能將會在背景自動同步您的所有資料。

### ⚠️ 手動啟用同步 (針對開發者模式)
由於目前尚未正式上架，若要在不同電腦間同步，您需要固定您的「擴充功能 ID」。請透過瀏覽器產生您專屬的金鑰：
1. 將專案資料夾壓縮成 `.zip` 檔案。
2. 前往 [Chrome Developer Dashboard](https://chrome.google.com/webstore/devconsole) (需登入 Google 帳號)。
3. 點擊「新增項目 (Add new item)」並上傳您的 `.zip` 檔（**註：只需要上傳，不需支付 5 美金費用，也不需正式發布**）。
4. 上傳成功後，在該項目的左側選單進入「套件 (Package)」頁面。
5. 點擊「查看公開金鑰 (View public key)」，這會顯示一段長字串。
6. 複製該字串，貼回您本地專案 `manifest.json` 中的 `"key": "..."` 欄位中。
7. 以後在任何電腦載入此專案，ID 均會相同，自動同步功能即可正常運作。

---

> **Note**: 雖然擴充功能支援自動同步，但仍建議您定期使用「匯出」功能將重要資料備份為 JSON 檔案，以策安全。
