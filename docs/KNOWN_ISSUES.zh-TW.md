# 已知問題 (Known Issues)

[English](KNOWN_ISSUES.md) | **繁體中文**

本文件紀錄了 **YouTube Study Companion** 目前已知的問題、限制以及建議的解決方法。

## 當前已知問題

### 1. 影片切換後的播放按鈕延遲 (Play/Pause Lag)
*   **問題描述**: 在切換到新影片後的最初幾秒鐘，使用滑鼠點擊側邊欄的播放/暫停按鈕可能會沒有反應。
*   **影響範圍**: 播放器控制 (Player Controls)
*   **暫時解決方案**: 使用鍵盤快捷鍵 `Space` 或 `K` 依然有效。或是等待約 2-3 秒後再進行點擊。

### 2. 浮動視窗關閉後的生命週期問題
*   **問題描述**: 當您關閉浮動視窗 (Pop-out Window) 時，若原來的瀏覽器分頁已導航離開 YouTube，擴充功能可能無法自動恢復側邊欄。
*   **影響範圍**: 浮動視窗 (Pop-out Window) / 側邊欄同步
*   **暫時解決方案**: 請手動回到 YouTube 影片頁面，並再次點擊瀏覽器工具列中的擴充功能圖示以重新開啟側邊欄。

### 3. 不同瀏覽器間的同步限制 (Sync Key Issue)
*   **問題描述**: 由於本擴充功能目前尚未在瀏覽器商店上架，因此預設的 `manifest.json` 中沒有包含官方的 API Key。這會導致不同瀏覽器（或不同電腦）間的自動同步功能預設是不啟動的。
*   **影響範圍**: 跨裝置同步 (Cross-Device Sync)
*   **解決方案**: 使用者需手動在 `manifest.json` 中設置自己的 API Key，或等待未來正式上架版本。

## 已修復或限制

### 1. Chrome 擴充功能同步延遲
*   **描述**: 由於 Chrome Sync API 的限制，跨裝置同步可能會有數秒到數分鐘的延遲。
*   **現狀**: 這是瀏覽器平台的限制。建議在更換裝置後稍等或重新整理頁面。

### 2. YouTube 介面變更導致的失效
*   **描述**: YouTube 頻繁更新介面可能會導致側邊欄無法正確偵測影片。
*   **現狀**: 我們會持續關注並更新程式碼。若發生此情況，請嘗試點擊標題列的 **Detect Video (🪄)** 按鈕。
