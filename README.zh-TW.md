# YouTube Study Companion v3.0.1

專業的 YouTube 播放控制與學習工具。將您的 YouTube 體驗轉變為強大的學習和筆記工作站。

📖 **[閱讀使用手冊](docs/USER_MANUAL.zh-TW.md)** | ⚠️ **[已知問題列表](docs/KNOWN_ISSUES.zh-TW.md)** | 📺 **[觀看產品簡報](https://youtube-study-companion-2azj231.gamma.site/)**

## 📥 安裝說明

本專案是一個瀏覽器擴充功能 (Browser Extension)，目前支援 Chrome 與 Edge 瀏覽器。請依下列步驟以開發者模式安裝：

1. **取得程式碼**
   
   下載此專案的 ZIP 檔並解壓縮，或是使用 Git Clone：
   ```bash
   git clone https://github.com/victor-hsu0618/youtube-sidebar-control.git
   ```

### 📦 安裝步驟 (建議)
1. **下載儲存庫**：點擊綠色的 "Code" 按鈕並選擇 **Download ZIP**。
2. **下載預先打包的擴充功能**：或者，您可以直接下載位於儲存庫根目錄的 `YouTubeStudyCompanion.zip`。
3. **解壓縮 ZIP**：在您的電腦上解壓縮該檔案。
4. **載入至 Chrome**：
   - 開啟 Chrome 並進入 `chrome://extensions/`
   - 開啟右上角的 **開發者模式** (Developer mode)。
   - 點擊 **載入未打包項目** (Load unpacked) 並選擇解壓縮後的資料夾。

## 🌟 3.0 全新功能 (v3.0 New)

### 1. 🎵 群組播放 (Group Play / Playlist Mode)
- **連續播放**：自動按順序播放特定收藏群組中的所有影片，無需手動切換。
- **視覺化模式指示**：當群組播放啟動時，介面會呈現專業的綠色光暈與狀態橫幅，顯示目前為「專注學期模式」。
- **清單自動匯入**：一鍵偵測並匯入整個 YouTube 播放清單至您的收藏群組中。

### 2. ⚡ 零延遲互動架構
- **混合同步技術**：結合 `chrome.storage.session` 與 `MutationObserver`，實現 <5ms 的 UI 回饋速度，操作更流暢。
- **持久化彈出視窗**：在側邊欄與獨立彈出視窗間無縫切換，狀態不中斷。

## 🌟 核心功能 (Legacy v2.x)

### 3. 🎛️ 進階播放控制
- **雙面板工作區**：專用的 **Markers (標記)** 與 **Advanced (進階)** 子分頁，最大化垂直空間。
- **整合式 A-B 循環**：直接在進度條上顯示 **A/B 視覺標記**，可精確設定循環起點與終點。
- **精確速度控制**：支援 **0.05x 單位** 的細微調整 (0.25x 至 3.0x)。

### 4. 🔖 智慧標記
- **時間戳記筆記**：在影片任何時刻新增標記。
- **標記追隨 (Follow)**：自動捲動功能，確保當前標記始終可見。
- **快捷鍵支援**：完整支援 `A` (新增標記) 與 `R` (重啟標記) 等鍵盤操作。

### 5. 💎 Pro 雲端驗證與版本限制
- **免費版限制 (Free)**：影片庫最多儲存 10 部影片，每部影片最多新增 10 個標記。
- **專業版 (Pro)**：解除所有數量限制，無限儲存影片與標記，並享有完整進階功能。
- **帳戶綁定**：系統自動識別 Google 帳戶 Email。
- **雲端授權**：權限跟隨帳號，跨裝置自動同步，換電腦也無需重新啟用。

### 6. 💾 影片庫與批量操作
- **多重工作階段**：同部影片可儲存多組不同的學習筆記與循環點。
- **批量編輯**：支援一次勾選多部影片進行移動、刪除或加入群組。

## 🛠️ 使用方式

1. **開啟**：在 YouTube 頁面點擊擴充功能圖示。
2. **群組播放**：進入 **Favorites**，選擇群組後點擊 **▶ Play Group**。
3. **儲存**：點擊愛心圖示將當前影片加入您的影片庫。
4. **快捷鍵**：點擊標題列的 **鍵盤圖示** 即可查看完整的 **快捷鍵指南**。
